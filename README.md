# VPN-бот (Telegram + Marzban + Platega)

Продажа VPN-подписок в Telegram: оплата через Platega, выдача и продление подписок через Marzban,
пробные 7 дней и реферальная система (+7 дней) — только после подписки на канал.

## Структура проекта (намеренно простая)

| Файл | Что внутри |
|---|---|
| `bot.py` | весь бот: меню, кнопки, тексты, инструкции по устройствам, админка |
| `config.py` | **все настройки и ключи** (токен, Marzban, Platega, канал, оператор) |
| `database.py` | SQLite (`bot.db`): юзеры, серверы/локации, подписки, платежи, рефералы |
| `marzban.py` | создание/продление пользователей в Marzban |
| `platega.py` | создание и проверка платежей Platega |
| `webhook.py` | *необязательно*: мгновенный приём callback от Platega |
| `banner.jpg` | баннер главного меню — **замени своим файлом** |
| `.env` | секреты (создай из `.env.example`) |

## Быстрый запуск

```bash
cd vpn_bot
pip install -r requirements.txt
cp .env.example .env   # и впиши свои значения в .env
python bot.py
```

## Что обязательно настроить перед запуском

1. **Токен бота** — у @BotFather → `BOT_TOKEN`.
2. **Свой Telegram ID** → `ADMIN_IDS` (узнать можно у @userinfobot). Можно несколько через запятую.
3. **Канал** → `CHANNEL_ID` (например `@myvpnchannel`) и `CHANNEL_URL`.
   ⚠️ **Бот должен быть администратором канала**, иначе он не сможет проверять подписку
   (а без этого не работают пробный период, рефералка и реферальные бонусы).
4. **Marzban** → `MARZBAN_URL` (адрес панели без слэша в конце), логин и пароль админа панели.
5. **Тег инбаунда Польши**: при первом запуске в БД создаётся локация «🇵🇱 Польша» с тегом-заглушкой
   `VLESS-TCP`. Открой панель Marzban → **Inbounds** → посмотри точное название (tag) своего инбаунда и:
   - либо поправь его в `database.py` (функция `init_db`, строка с `add_location`) **до первого запуска**,
   - либо, если `bot.db` уже создалась, выполни: `sqlite3 bot.db "UPDATE locations SET inbounds='{\"vless\": [\"ТВОЙ-ТЕГ\"]}' WHERE code='pl';"`
   - Протокол по умолчанию `vless`. Если у тебя другой — поменяй `MARZBAN_PROTOCOL` в `config.py`.
6. **Platega** → `PLATEGA_MERCHANT_ID` и `PLATEGA_SECRET` (личный кабинет Platega → Настройки).
   Также укажи `PLATEGA_RETURN_URL` / `PLATEGA_FAILED_URL` — куда отправлять юзера после оплаты
   (удобно: ссылка на твоего бота `https://t.me/username_бота`).

## Меню бота

- **🔌 Подключиться** (синяя кнопка) — выбор сервера → тариф → оплата.
- **🎁 7 дней бесплатно** — пробная подписка, только после подписки на канал, 1 раз.
- **👤 Профиль** — ID, дата регистрации, подписки, рефералы, бонусные дни.
- **📋 Мои подписки** — список подписок, ссылка, инструкция, продление.
- **🤝 Партнёрам** — прямая ссылка на оператора @theeveryesha.
- **🆘 Поддержка** — оператор @theeveryesha.
- **👥 Реферальная система** — ссылка `https://t.me/<бот>?start=ref_<id>` (только после подписки на канал).
- **ℹ️ Инфо** — Пользовательское соглашение и Политика конфиденциальности (Telegraph).

После успешной оплаты (и после активации пробной подписки) бот показывает кнопки устройств:
**Android / iOS / Windows / macOS**. По нажатию юзер получает инструкцию именно под своё устройство
и свою ссылку подписки. Тексты инструкций правятся в `bot.py`, словарь `INSTRUCTIONS`.

## Тарифы и цены

1 месяц = **100 ₽**, дальше — выгоднее за месяц: 3 месяца = **270 ₽** (90 ₽/мес),
6 месяцев = **480 ₽** (80 ₽/мес), 12 месяцев = **840 ₽** (70 ₽/мес).
Количество дней: 30 / 90 / 180 / 365. Цены хранятся **у каждого сервера отдельно** и меняются из бота.

## Оплата (Platega) и заглушка

- Создание платежа: `POST https://app.platega.io/v2/transaction/process`, проверка: `GET /transaction/{id}`
  (документация: https://docs.platega.io). Статусы: `CONFIRMED` — оплачено, `CANCELED` — отменено.
- Выдача подписки происходит тремя путями (что сработает первым): кнопка «✅ Я оплатил — проверить»,
  фоновая автопроверка каждые 30 секунд, и (если запустишь) `webhook.py`.
- **Заглушка оплаты**: команда админа `/payment_toggle` включает/выключает оплату.
  Когда выключена, при нажатии оплаты бот отвечает:
  *«Извините, оплата в данный момент времени недоступна. Попробуйте позже»*.
  Начальное значение — `PAYMENT_ENABLED` в `config.py` / `.env`.

Необязательный webhook для мгновенной выдачи:

```bash
python webhook.py   # слушает 0.0.0.0:8080, путь /platega-callback
```
И укажи в кабинете Platega Callback URL: `https://твой-домен/platega-callback` (HTTPS обязателен).

## Реферальная система (+7 дней)

1. Пользователь открывает «Реферальная система» — доступ только если он подписан на канал.
2. Друг переходит по его ссылке и запускает бота (в этот момент бонус ещё НЕ начисляется).
3. Друг **вступает в канал** — в этот момент пригласивший получает **+7 дней**:
   к активной подписке (сразу и в Marzban), а если подписки нет — дни копятся и автоматически
   применятся при первой покупке/пробной подписке.
   Бот ловит вступление сам (если он админ канала), а также при нажатии другом кнопок
   «Я подписался» в разделах «7 дней бесплатно» / «Реферальная система».

## Админ-команды (только для ADMIN_IDS)

| Команда | Что делает |
|---|---|
| `/admin` | список админ-команд |
| `/add_location` | добавить новый сервер по шагам: название → код латиницей → тег инбаунда Marzban → 4 цены |
| `/locations` | все серверы: включить/выключить продажу, скрыть сервер |
| `/edit_price` | изменить цену любого тарифа любого сервера (кнопки → ввести новую цену) |
| `/broadcast` | рассылка всем пользователям: пришли текст/фото/видео → предпросмотр → отправить |
| `/payment_toggle` | включить/выключить оплату (заглушка) |
| `/stats` | пользователи, активные подписки, платежи, выручка |
| `/cancel` | отменить текущее действие (добавление сервера, рассылку и т.п.) |

Удаление сервера сделано «мягким»: сервер скрывается из продажи, а уже выданные подписки
и история платежей не ломаются. Вернуть сервер обратно — `/locations` → «Вкл».

## Частые проблемы

- **«Не могу проверить подписку на канал»** — бот не админ канала или неверный `CHANNEL_ID`.
- **Marzban: 404/422 при создании юзера** — неверный тег инбаунда (см. пункт 5 выше) или протокол.
- **Платёж оплачен, подписки нет** — подожди до 30 сек (автопроверка) или нажми «Я оплатил»;
  если Marzban был недоступен, бот будет повторять выдачу сам, платёж не потеряется.
- **Сменить баннер** — просто замени файл `banner.jpg` своим (рекомендуется ~1280×640).
